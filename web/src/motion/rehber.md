# `motion/` — animasyon ve motion bileşenleri

Framer Motion / `motion/react` sarmalayıcıları; kabuk ve harita chrome’unda kullanılır.

| Dosya | Tipik kullanım yeri |
|-------|---------------------|
| `MorphHover.tsx`, `MorphHoverButton` | Sidebar pin, rail butonları |
| `MotionToast.tsx`, `MotionBanner` | API hata bandı, snapshot toast |
| `MotionModal.tsx`, `MotionSheet.tsx`, `MotionDrawer.tsx` | Modallar |
| `StageTabs.tsx`, `StageTabPanels.tsx` | Servis sekmeleri |
| `MotionList.tsx` | Arama hit listesi animasyonu |
| `DockMagnifyRow.tsx` | Harita dock büyütme satırı |
| `config.ts` | Süre, easing sabitleri |

CSS animasyonları ayrıca `App.css` / `service-map.css` içinde tanımlı olabilir.
